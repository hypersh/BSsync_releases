# BS Sync Releases

BS Sync의 Windows 배포 파일과 사용자 설명서를 제공하는 공개 다운로드 저장소입니다.
Python 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드

- [최신 Release 보기](https://github.com/hypersh/BSsync_releases/releases/latest)
- Release의 **Assets**에서 Windows 실행 파일과 한국어·영문 설명서를 다운로드할 수 있습니다.

## BS Sync 소개

BS Sync는 Source 폴더의 파일을 Target 폴더로 복사·동기화하는 Windows용 수동 실행(On-Demand) 파일 동기화 프로그램입니다. 분석, Mirror, Destination Newer Protection, Safety Guard, Safe Stop 및 사용자 지정 제외 폴더 기능을 제공합니다.

중요한 데이터에는 BS Sync와 별개의 백업도 유지하고, Mirror 실행 전에는 분석 결과의 삭제 목록을 확인하십시오.

This public repository provides the Windows release files and user guides for BS Sync. Python source code is not included in this repository.

## Download

- [View the latest release](https://github.com/hypersh/BSsync_releases/releases/latest)
- Download the Windows executable and the Korean or English user guide from the release **Assets** section.

BS Sync is a Windows on-demand file synchronization utility that copies and synchronizes files from a Source folder to a Target folder. It includes analysis, optional Mirror mode, Destination Newer Protection, Safety Guard, Safe Stop, and user-defined excluded folders.
