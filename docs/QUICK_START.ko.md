# BS Sync 시작 안내

[3.1.0 다운로드](https://github.com/hypersh/BSsync_releases/releases/download/v3.1.0/BS_Sync310.exe) · [소개로 돌아가기](../README.ko.md) · [English](QUICK_START.md)

BS Sync는 Windows x64용이며 Windows 11에서 검증했습니다. 개인과 기업 모두 무료로 사용할 수 있습니다.

## 1. 설치하고 언어 선택하기

`BS_Sync310.exe`를 설치하고 **BS Sync 3**를 엽니다. 작업 중이 아닐 때 오른쪽 위에서 **한국어** 또는 **English**를 선택하세요. 선택은 다음 실행에도 유지됩니다. Windows 기본 대화상자는 운영체제의 언어를 따릅니다.

현재 설치파일에는 디지털 서명이 없습니다. 설치 전 [다운로드 확인](#다운로드-확인)을 참고하세요.

## 2. 폴더와 모드 정하기

서로 다른 두 폴더를 **A 폴더**, **B 폴더**로 지정하고 작업 이름과 필요한 **제외 폴더**를 입력합니다. 한 폴더가 다른 폴더의 하위에 있으면 안 됩니다.

| 모드 | 사용하는 경우 | 삭제 동작 |
|---|---|---|
| **동기화** | 양쪽에서 작업하며 확인된 변경을 서로 반영하려는 경우 | 확인된 삭제도 전달합니다. 삭제와 반대쪽의 독립적인 수정·이동이 충돌하면 선택이 필요합니다. |
| **복사 (Mirror)** | 한쪽을 기준으로 다른 쪽을 맞추려는 경우. **A → B** 또는 **B → A**를 선택합니다. | **대상에만 있는 항목은 삭제합니다.** 방향과 제외 항목을 확인하세요. |

동기화는 이전본을 보관합니다. 복사에서는 덮어쓰기·삭제 후에도 이전본을 남기려면 **덮어쓰기·삭제 전 이전본 보관**을 선택합니다. 보관 기간은 7일·30일·90일·**계속 보관** 중 정합니다.

## 3. 분석하고 확인한 뒤 실행하기

**분석 시작**을 누릅니다. 선택이 필요한 항목은 다음과 같이 정합니다.

| 선택 | 의미 |
|---|---|
| **A 사용** | A의 현재 상태를 반영합니다. A에 없는 항목이면 B에서 삭제합니다. |
| **B 사용** | B의 현재 상태를 반영합니다. B에 없는 항목이면 A에서 삭제합니다. |
| **양쪽 삭제** | 선택한 항목을 A/B 양쪽에서 삭제합니다. |
| **보류** | 이번 실행에서는 해당 항목을 그대로 둡니다. |

폴더 선택은 하위 항목에도 적용되며 제외 항목은 보호합니다. 복사·삭제 예정 내용을 확인한 뒤 **동기화 실행** 또는 **복사 실행**을 누릅니다. 화면에는 문제와 선택 항목을 중심으로 표시합니다. **결과 파일 보기**에서는 전체 분석·실행 결과를 볼 수 있으며, 분석 보고서에는 변경 없는 항목도 포함됩니다.

접근할 수 없거나 분석 이후 바뀐 항목은 보류합니다. 독립적인 다른 항목은 처리될 수 있으므로 완료인지 부분완료인지 확인하세요. 표시된 원인을 해결한 뒤 다시 분석합니다. **중지**를 누르면 안전하게 중지하도록 요청하며, 다음 분석에서 미완료 작업을 확인한 뒤 새 계획을 만듭니다.

## 기록과 이전본은 어디에 있나요?

다음 위치는 서로 다른 역할을 합니다.

| 위치 | 내용 |
|---|---|
| **각 A/B 폴더 안의** `_BS_Sync_Data_v3` | 폴더 식별 정보와 전달 가능한 동기화 이력입니다. 일반 동기화·복사 작업에서 보호합니다. |
| **이 PC의** `%LOCALAPPDATA%\BS_Sync3` | 로컬 상태 DB, 저장한 작업·설정, `reports` 폴더입니다. |
| 작업 폴더의 상위 → `_BS_Sync_Recovery` → Replica ID | 보관한 이전본과 복구 파일입니다. 일반적으로 선택한 A/B 폴더 밖에 있습니다. |

예를 들어 `D:\Work\Photos`는 보통 `D:\Work\_BS_Sync_Recovery\<replica-id>`를 사용합니다. UNC 공유 전체를 루트로 선택했다면 복구 폴더는 그 공유 내부에 생깁니다. **이전본 · 복구 위치**에서 실제 경로를 확인할 수 있습니다.

오류를 없애기 위해 이 기록들을 삭제하지 마세요. 이 PC의 앱 데이터를 백업하려면 BS Sync를 닫고 `%LOCALAPPDATA%\BS_Sync3` 폴더 전체를 복사합니다. 앱 실행 중 `bssync.db`만 복사하는 방식은 피하세요.

## 자주 묻는 질문

**처음 동기화하면 어떻게 되나요?** 이전 이력이 없으면 내용이 같은 파일은 복사하지 않습니다. 같은 경로의 내용이 다르면 선택이 필요합니다. 한쪽에만 있는 파일은 과거 삭제 여부를 알 수 없으므로 반대쪽에 복사합니다. 복사 모드는 지정한 방향을 따릅니다.

**3.0.1에서 업데이트할 수 있나요?** 가능합니다. 3.1.0을 설치하면 기존 설치 식별 정보, 저장한 작업, v3 이력과 복구 기록을 유지합니다. 업데이트 전에 기존 DB를 삭제하지 마세요.

**반복 분석도 시간이 걸리는 이유는 무엇인가요?** 새 파일과 삭제를 찾기 위해 폴더 목록과 파일 정보를 확인하며, 내용이 그대로인 파일의 기록은 재사용합니다. **정밀 검사(느림)**는 전체 내용을 읽습니다. 파일 수, 저장장치, 백신과 네트워크 지연에 따라 소요 시간이 달라집니다.

## 다운로드 확인

[설치파일](https://github.com/hypersh/BSsync_releases/releases/download/v3.1.0/BS_Sync310.exe)과 [SHA-256 파일](https://github.com/hypersh/BSsync_releases/releases/download/v3.1.0/BS_Sync310.exe.sha256)을 내려받습니다. 다운로드 폴더에서 PowerShell을 열고 실행합니다.

```powershell
Get-FileHash -LiteralPath .\BS_Sync310.exe -Algorithm SHA256
```

3.1.0의 SHA-256은 다음과 같습니다.

```text
e289c1ca3aa6e38edb0a81e87d982971e7aaaa81a4d4404f322bdd8f245e9581
```

설치파일 크기는 17,066,108바이트입니다. 해시 문자열의 대소문자는 상관없습니다. 일치하는 해시는 공개한 체크섬과 파일을 대조하는 수단이며 디지털 게시자 서명을 대신하지 않습니다. 현재 설치파일은 **NotSigned**로 표시됩니다. Windows 또는 조직 정책에서 설치를 차단한다면 해당 보안 정책을 따르고 보호 기능을 유지하세요.

도움이 필요하면 [오류 제보](https://github.com/hypersh/BSsync_releases/issues/new?template=bug_report.yml)를 한국어 또는 영어로 작성할 수 있습니다. 제보는 공개됩니다. 예제 파일명을 사용하고 개인 경로·비밀번호·개인정보를 지워 주세요. 첨부는 선택 사항이며, 최초 제보에 원본 문서나 앱 DB 전체는 필요하지 않습니다.
